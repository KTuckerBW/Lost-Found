Instructions on how to download the csv parser package
(FOR INTELLIJ)
1) go to https://repo1.maven.org/maven2/org/apache/commons/commons-csv/1.14.1/
2) download commons csv-1.14.1.jar
3) Do Ctrl+Alt+Shift+S (windows) or Cmd+; (Mac) 
3.5) Or go to your Project structure screen if this isn't working 
4) On the left sidebar, click Modules and select Dependencies 
5) Click on the + icon
6) Select JARS or Directories 
7) Choose the filepath for what you just downloaded from Maven 
8) Apply
